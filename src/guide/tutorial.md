# 遊び方

将棋タクティクスは、タクティクスオウガというテレビゲームを、将棋盤の上で遊ぶために考えられたゲームです。  

使う道具は将棋のものですが、ゲームの仕組みやルールはタクティクスオウガに倣ったものになっています。  
プレイ人数は2人、1回遊ぶのにだいたい30分から1時間程度かかります。  

まずは基本的な遊び方を説明します。  

## 1. 将棋盤を用意しよう

遊ぶためには将棋盤が必要です。  
将棋盤には以下のように並べてください。  

<img src="TODO" alt="将棋盤上の初期配置" />

```
　金　銀　  
角香王桂飛  
```

手前側と奥側でプレイヤーが別れます。先手と後手を決めておきましょう。  

## 2. アプリを立ち上げて、対戦を始めましょう

1. アプリケーションにアクセスしてください。  
  [将棋タクティクス](https://motojouya.github.io/shogi_tactics/)  
2. `バトルの管理`をクリックします。  
3. `新しく作る`をクリックします。  
4. `バトルをスタート`をクリックしてください。  
  モードは通常モード、先手と後手にはプレイヤー名を入力してください。  

モードには、通常モードと、戦乱モードがあります。  
[戦乱モード](TODO)で遊びたい場合は、別のページの説明を参照してください。  

## 3. 駒を動かしましょう

ここから対戦開始です。  
将棋はプレイヤーごとにターンがありますが、将棋タクティクスは、駒ごとにターンがあります。  

ターンがやってきた駒が、画面上に表示され、行動選択ができるようになっています。  
その駒が先手であるなら先手が、後手なら後手のプレイヤーが操作してください。  

一つのターンにできることは、以下の2つです。
- 駒の位置を動かす移動
- 相手にダメージを与えるなどの行動

駒は、上下左右に決められたマスの数だけ移動することができます。駒ごとに移動できるマス数は決まっていて、画面に表示されます。  
既に駒があるマスには移動できません。また敵がいるマスは通過することもできません。  

行動は2つのうちから1つを選べます。強い行動はコストが高く、弱い行動はコストが低いです。  
選んだ行動を受ける駒の数は決まっています。画面に表示されている行動が届く範囲にいる駒を選んで、行動を受ける駒を選択してください。  

もちろん、移動も行動もしなくても構いません。`何もしない`という選択肢が画面上にもあります。  

### 行動順について

コストという言葉が出てきました。  
通常モードの場合は、駒の行動順は最初は以下の順番で回ってきます。  

飛(先手) → 飛(後手) → 角(先手) → 角(後手) → 金(先手) → 金(後手) → 銀(先手) → 銀(後手) → 桂(先手) → 桂(後手) → 香(先手) → 香(後手) → 王(先手) → 王(後手)

選択した行動のコストが高いと、ターンが回ってくる順番が後ろに回ります。  
コストの低い行動を選ぶか、高い行動を選ぶか、1つの選択が勝敗を分けることもあるでしょう。  

行動順の考え方についての詳細は、[アプリなしでの遊び方](TODO)を参照してください。  

## 4. ターンを繰り返しましょう

移動は、プレイヤー自身が管理します。行動はアプリケーションで入力します。  
行動を入力したら、次に行動できる駒のターンです。  

このターンを繰り返していきましょう。  
行動を行うと、相手のHPを減らすことができます。  
HPが0になった駒は、盤面から取り除きましょう。将棋のように駒を復帰させることはできません。  

相手のリーダのHPを0にしたら勝利です。通常モードの場合、`王将(将軍)`がリーダです。  
ここまでわかれば、あとは戦うのみです。勝利を目指して頑張ってください。  

また、正確なルールは、[ルール](TODO)を参照してください。  

## 5. 画面上の項目を確認しよう

前段までの知識があれば遊ぶことはできますが、やはり少しコツを知っていたほうがいいでしょう。  
タクティクスオウガを遊んだことがある人にとっては当たり前の知識なので、不要であれば読み飛ばしてください。  

まずは、アプリケーション画面に表示されている駒の行動順を確認するようにしましょう。  
次に自分の駒が動くのか、相手の駒が動くのか。駒の位置と行動順から、相手の駒は倒し切れるのか。  
基本的に、各個撃破が戦術の基本です。一気に近づいて、一気に倒すように行動順を意識しましょう。  

## 6. 壁を作ろう

金将(重装兵)、銀将(野伏)、戦乱モードで使える竜馬(宝蔵院)には、`足止め`という性質が備わっています。  
たとえば相手の香車(薙刀)が、重装兵の隣のマスを通過しようとしたとき、必ず隣のマスで停止しなくてはなりません。  

隣のマスから動く場合は、薙刀の移動マス数の4マス動けます。  
ですが、重装兵の隣接マスを超えて4マス動かすことはできません。  

これが`足止め`です。
野伏、宝蔵院も同じ性質を持っています。  

<img src="TODO" alt="足止めで進めない薙刀" />
// 足止めされて隣接マスまで移動する図と、その先に移動できない図を並べる感じに

また重装兵は、`迎撃体制`ができるので、これを行うと相手の行動で受けるダメージを1減らすことができます。  
相手の行動で発生するダメージが1の場合は、ダメージが0になります。  
野伏の場合は、`矢かわし`できるので、遠隔攻撃が無効になります。  

これらの駒は積極的に前に出しても、比較的安心です。また、`足止め`によって、相手の駒が、自分の駒に近づかないように壁になることができます。  
これらの壁を前に出し、その後ろに控えた飛車(軽弓)、角行(強弓)で相手を攻撃するのが、基本的な戦術です。  

## 7. 相手の壁を崩すには

ここからは、プレイヤー自身で試行錯誤してください。  
自分が重装兵や野伏で壁を作るということは、相手も同じことをしてくるということです。  

これらのの仕組みを利用するか、あるいは意表をつくような駒の運用をするか。  
工夫して相手を倒す。これが将棋タクティクスの醍醐味です。  
ぜひ、楽しんで遊んでください。
