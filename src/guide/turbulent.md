# 戦乱モード

このアプリケーションには、通常モードと戦乱モードがあります。  
将棋タクティクスを遊ぶにあたって、アプリケーションを使うのであれば、どちらを選ぶか決めなくてはなりません。  

通常モードは、[遊び方](TODO)で説明した通りです。  
戦乱モードの大きな違いは、使う駒を選択できることです。また、自軍のリーダーとなる駒も選択できるので、将軍以外をリーダーにすることができます。  

戦乱モードの遊び方を説明していきます。  

## 1. 将棋盤を用意しよう

将棋盤を用意するのは、同じです。  
ただし、どの駒を出すかは、先手後手どちらも決めていません。まだ駒を並べる必要がありません。  

## 2. アプリを立ち上げて、対戦を始めましょう

[将棋タクティクス](https://motojouya.github.io/shogi_tactics/)アプリケーションにアクセスして、バトルを開始するのも同じです。  
ただし、新しくバトルを作る際に、`戦乱モード`を選びます。  
先手後手のプレイヤー名を入力するのは同じですが、新しく2つの項目が追加されています。

- 駒数
- 基礎コスト

駒数は単純です。先手後手それぞれが選択できる駒の数です。  
基礎コストは、特定の駒にターンが回ってきたときにかかるコストです。この基礎コストは行動をしなくても必ず加算されます。  
コストが合計で少ない駒からターンが回ってきます。そのコストにターンが回ってくるごとに必ず加算されるのが基礎コストです。  

基礎コストをコントロールすることで、ゲームの難易度を劇的に調整することができますが、込み入った話になりすぎるので、ここでは割愛します。  
詳細を理解したい場合は、[アプリなしでの遊び方](TODO)を参照してください。  

## 3. 駒を登録しよう

バトルを始めても、最初に行うのは駒の登録です。  
これは先手から、交互に行います。  

駒を決めたらアプリケーションに入力すると同時に、盤面にも配置します。  
盤面は、自軍側2マス分の幅であれば、どこに配置しても構いません。  
ただ、一度配置したら、変更はできません。つまり先に配置したほうが、先に配置を見られるので不利です。  
先に駒を動かす権利を持つ先手が、その不利を被るのがふさわしいでしょう。  

<img src="" alt="配置可能な場所を示した将棋盤" />

交互に駒を登録、配置していき、お互いに先に決めた駒数に達したら、対戦開始です。  
先手後手ともにリーダは必ず1つ駒に設定しなくてはなりません。これも画面から選べます。  

## 4. 対戦開始

[遊び方](TODO)で説明した通り、同じように対戦します。  

戦乱モードでは、選べる駒が増えています。ゲームバランスを壊しかねないような性質を持った駒もあります。  
対戦を楽しむ場合には、特定の駒を禁止するなど工夫するといいかもしれません。  
通常モードでは味わえない、緊張感のある対戦ができるはずです。
