
# 将棋タクティクス

## ゲームの概要
将棋の駒を用いて、タクティクスオウガをやってしまおうというゲーム。  
駒の他にターン管理を行うアプリケーションを利用する。ない場合は紙とペンで代用可能。  

モードとして、通常モードと戦乱モードがある。

## モードごとの違い

### 通常モード
王の位置は本将棋と同じで、その周りに以下のように並べる  
余った駒は、各駒の体力分かさねて配置する。これで全ての駒を利用することになる。  

　金　銀　  
角香王桂飛  

駒の初期の順番は以下の通り  
飛->角->金->銀->桂->香->王  

先攻後攻はじゃんけん等で決める。  
勝利条件は王を倒すこと。  

### 戦乱モード
駒の配置、数、順番は自由だが、推奨の駒数は9  
通常モードで使わない駒も利用可能で、選択し、動かす順番も自由に決める。  
そのため、駒1セットでは不足するので、複数セット必要。  

先に動かす順番を決め、先攻から先に駒を交互に配置していく。  
先攻のほうが先に駒の配置が明かされるので不利だが、先に動かせる利点がある。  
また、障害物をお互い、いくつか配置してもよい。これは自陣と敵陣以外ならどこでも配置可能  

駒の配置は、自陣2行目であれば、どこに配置してもよい  
勝利条件は王を倒すでもいいし、殲滅でもよい。  

## 進行
駒ごとにターンがあり、順番に行動していく。  
ターンには移動と行動ができ、移動はコストがないが、行動はコスト2、反動行動はコスト7である。  
コストがかかると、ターンがコスト分だけ後ろにずれる。ずれた先、あるいはずれなくても、同じコストの駒がいる場合は、元の順番通りになる。  
攻撃を受けると、攻撃分だけ体力が減少し、体力が0になると駒は除去される。  

## 開発
ターン管理アプリがいる。  
ダメージ管理は無いので、アクションの際の効果は不要だが、キャラを除外する機能が必要。  
駒のビジュアルは決まっているので、それについても用意する。  
戦乱モードの場合は、駒の選択と順番を定義する機能もいる。
